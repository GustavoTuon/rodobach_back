# Pagamento e descarga — publicação

Publicar o backend e o frontend das branches de melhorias de 26/10/2026.
Antes de iniciar o backend atualizado, aplicar somente as migrações novas:

```sh
node scripts/apply-plantao-payment-method.mjs
node scripts/apply-plantao-unloading.mjs
```

Os scripts são idempotentes e registram checksum em `schema_migrations`.
Preservam os registros antigos e acrescentam campos opcionais no banco.
Pagamentos novos exigem uma forma ativa do cadastro do ERP; pagamentos
antigos continuam aparecendo sem forma informada até serem atualizados.

Descarga exige viagem da placa, CT-e autorizado vinculado à viagem,
descrição e escolha explícita de reembolso. A API consulta e valida o ERP;
o registro da despesa e sua auditoria são gravados no Rodobach, sem criar
movimentação financeira no ERP.

A permissão `conferencia-manutencao` controla pagamentos e conferência.
O perfil motorista continua sem acesso a essas operações.

O alerta de bateria é um processo separado e não inicia com a API.
Configuração, limites e comandos estão em `BATTERY-ALERTS.md`.
